# Алхимия: Слаймовый прорыв

Аркадный слэшер для FunFlow Game Jam x ТПУ, вариант 3 «Разруби!».

В королевской лаборатории взорвался автоклав, и зелье ожило. Вы — верховный алхимик с Эфирным серпом: рубите слаймов на лету и не задевайте чумные споры.

## Как запустить

1. Откройте проект в Unity **6000.6.5f1** (Unity 6.6).
2. Нажмите **Play**. Игровая сцена запустится сама, какая бы сцена ни была открыта.

Сборка не нужна: игра рассчитана на запуск в редакторе, на Windows и на Mac.

## Правила

- Зажмите левую кнопку мыши и проведите через слайма — он разрезан.
- Три слайма и больше одним взмахом — комбо, четыре и больше — «Перегрузка реторты» с удвоенными очками.
- Чумную спору (бомбу) резать нельзя: минус жизнь.
- Слайм, упавший обратно в котёл, — тоже минус жизнь. Жизней три.
- Золотой король — редкий бонус: замедляет время и превращает бомбы в золото. Он вылетает только в гущу событий, когда в воздухе тесно от слаймов и бомб.
- Серия — слаймы, разрубленные подряд без промаха. Её полоса в левом нижнем углу растёт от вехи к вехе
  (×10, ×30, ×50, ×100), на каждой вехе — бонус и новый уровень полосы.

Между попытками копятся цели: звание по рекорду (семь званий со своими значками), ступени комбо
(×5, ×10, ×15, ×20, ×25 одним взмахом) и лучшая серия.

Попытка длится от двух до пяти минут: темп растёт, пока котёл не возьмёт верх.

## Управление

| Действие | Клавиша |
|---|---|
| Взмах клинка | левая кнопка мыши и движение |
| Начать заново после поражения | щелчок или пробел |
| В меню | Esc |
| Предыстория (из меню) | пробел |
| Пауза и продолжение | правая кнопка мыши |
| Громкость (в меню и на паузе) | ползунок или колёсико мыши |

## Как устроен проект

Содержимое игры отделено от кода и лежит в `Assets/Resources` обычными ассетами:

| Что | Где | Как менять |
|---|---|---|
| Баланс: правила, кривые сложности, рисунки волн, порядок появления объектов, звания (пороги и цвета), ступени комбо, вехи серии | `Balance.asset` | в инспекторе Unity |
| Картинки, включая три слоя фона лаборатории | `Art/` — PNG по папкам | перерисовать или заменить файл, см. `Art/README.txt` |
| Звуки | `Sounds/` — WAV | отредактировать или заменить файл, см. `Sounds/README.txt` |
| Музыка боя | `Music/Gameplay.mp3` | заменить файл |
| Шрифты | `Fonts/` — Philosopher: полужирный для заголовков, обычный для текста; лицензия OFL лежит рядом | заменить файл шрифта |

Код в `Assets/Scripts` — по одному классу на одну обязанность:

| Файл | За что отвечает |
|---|---|
| `GameManager.cs` | состояния игры, счёт, жизни, комбо, замедление, тряска камеры |
| `Blade.cs` | клинок: ввод, след, попадание по траектории взмаха |
| `Sliceable.cs` | летающий объект: слайм или бомба |
| `Spawner.cs` | волны: как летит каждый рисунок; числа берёт из `Balance` |
| `Balance.cs` | описание ассета баланса |
| `Fx.cs` | половинки, брызги, кляксы, взрывы |
| `Art.cs`, `Sfx.cs` | загрузка картинок и звуков; если файла нет, создают его формулой |
| `Hud.cs`, `Story.cs` | интерфейс и комикс-предыстория |
| `ComboBar.cs` | полоска комбо с уровнями |
| `StreakBar.cs` | полоса серии без промаха |
| `Backdrop.cs` | фон лаборатории из слоёв: стена, полки по бокам, борт котла поверх слаймов |

`Assets/Editor/AlchemiaTools.cs` добавляет меню «Алхимия»: заново создать исходные картинки и звуки.
